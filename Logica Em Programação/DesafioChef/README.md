# 🍳 Desafio DevChef — Calculadora de Porções em Python

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade acadêmica de **Lógica de Programação**, com o objetivo de aplicar os conhecimentos de Python na criação de uma Ficha Técnica Digital para receitas culinárias.

O programa permite informar o nome do cozinheiro, a quantidade de porções da receita original e quantas porções deseja preparar. Com essas informações, o sistema calcula as novas quantidades dos ingredientes e apresenta o tempo estimado de preparo.

## 🎯 Objetivos da atividade

- Praticar lógica de programação utilizando Python.
- Trabalhar com entrada e saída de dados pelo terminal.
- Aprender a utilizar variáveis e operadores matemáticos.
- Calcular proporções para ajustar receitas.
- Utilizar `input()`, `print()`, conversões numéricas e f-strings.
- Organizar informações e apresentar resultados de forma clara.

## 🍽️ Receitas desenvolvidas

O repositório contém três programas independentes:

### 1. Cheesecake de Frutas Cítricas
Arquivo: `Receita1.py`

Programa que calcula as quantidades dos ingredientes para o cheesecake e sua calda cítrica, além de estimar o tempo total de preparo.

### 2. Gelato de Manga com Maracujá
Arquivo: `receita2.py`

Programa que ajusta as quantidades de manga, maracujá e iogurte de acordo com o rendimento desejado e apresenta o modo de preparo.

### 3. Nuggets Saudáveis
Arquivo: `receita3.py`

Programa que recalcula as quantidades de frango, temperos e ingredientes para empanar, considerando o número de porções desejadas e o tempo de preparo informado.

## 🧠 Conceitos de Python utilizados

- **Variáveis:** armazenamento dos dados da receita.
- **Entrada de dados (`input()`):** coleta das informações fornecidas pelo usuário.
- **Conversão de tipos (`int()`):** transformação das entradas em números inteiros.
- **Operadores aritméticos:** utilização de divisão, multiplicação e soma.
- **Fator de proporção:** cálculo utilizado para ajustar as quantidades dos ingredientes.
- **F-strings:** formatação dos resultados exibidos no terminal.
- **Saída de dados (`print()`):** apresentação da ficha técnica e do modo de preparo.

## ⚙️ Como funciona?

O programa solicita os dados ao usuário e calcula um fator de proporção com base na quantidade original e na quantidade desejada de porções.

A fórmula utilizada é:

`fator = porções desejadas / porções originais`

Depois, cada ingrediente tem sua quantidade multiplicada por esse fator. O programa também calcula o tempo total estimado e exibe as informações organizadas em uma ficha técnica digital.

## ▶️ Como executar

1. Tenha o Python instalado no computador.
2. Faça o download ou clone este repositório.
3. Abra a pasta do projeto no VS Code ou em um terminal.
4. Execute o arquivo da receita desejada.

Exemplo:

```bash
python Receita1.py
```

Para executar as outras receitas:

```bash
python receita2.py
python receita3.py
```
